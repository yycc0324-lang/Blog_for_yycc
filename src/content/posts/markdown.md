# 一个 h1 标题

段落之间用一个空行分隔。

这是第二段。_斜体_、**粗体**，以及 `等宽字体`。无序列表
长这样：

- 这一项
- 那一项
- 另外那一项

注意 --- 先不管星号 --- 正文内容其实是从第 4 列开始缩进的。

> 引用块就
> 这样写。
>
> 如果你愿意，它也可以
> 跨过多个段落。

用 3 个连字符表示破折号。用 2 个连字符表示范围（例如"它都在
第 12--14 章里"）。三个点 ... 会被转换成省略号。
支持 Unicode。☺

## 一个 h2 小标题

这里是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

再注意一次，正文内容是从第 4 列开始的（距左侧 4 个字符）。
这是一个代码示例：

    # Let me re-iterate ...
    for i in 1 .. 10 { do-something(i) }

如你所料，缩进 4 个空格就行。顺便提一句，如果你愿意，也可以
不缩进，改用围栏代码块：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

（这样复制粘贴更方便。）你还可以给围栏代码块标注语言，
让 Pandoc 给它做语法高亮：

```python
import time
# Quick, count to ten!
for i in range(10):
    # (but not *too* quick)
    time.sleep(0.5)
    print i
```

### 一个 h3 标题

现在是一个嵌套列表：

1. 首先，准备这些材料：

    - 胡萝卜
    - 芹菜
    - 小扁豆

2. 烧一些水。

3. 把所有东西倒进锅里，然后照着
   下面的算法来：

        find wooden spoon
        uncover pot
        stir
        cover pot
        balance wooden spoon precariously on pot handle
        wait 10 minutes
        goto first step (or shut off burner when done)

    别碰那把木勺，不然它会掉下来。

再注意一次，正文总是对齐到 4 个空格的缩进上（包括
上面延续第 3 项的那最后一行）。

这是一个指向 [某个网站](http://foo.bar) 的链接，一个指向 [本地
文档](local-doc.html) 的链接，以及一个指向 [当前文档中某个小节
标题](#一个-h2-小标题) 的链接。这里还有一个脚注 [^1]。

[^1]: 脚注的文字写在这里。
