**MDX（Markdown + JSX）** 在静态写作与应用界面之间架起了一座桥。在 Shirone 里，作者可以在文章正文中无缝混用动态逻辑、响应式的 Svelte 5 组件与 Material 3 设计令牌。

## 1. Markdown 与 MDX 能力对照

| 能力 | 标准 Markdown（`.md`） | Shirone MDX（`.mdx`） | 执行方式 |
| :--- | :--- | :--- | :--- |
| **排版与结构** | 完整支持 | 完整支持 | 静态 SSR |
| **代码高亮** | 行号、边框、可折叠 | 行号、边框、可折叠 | 静态 SSR（Expressive Code） |
| **图表与数学** | Mermaid、KaTeX | Mermaid、KaTeX | 客户端增强 |
| **提示框** | Note、Tip、Important、Warning、Caution | Note、Tip、Important、Warning、Caution | 静态 SSR |
| **M3E 展示原子** | 不可用 | 直接集成（`<Card>`、`<Skeleton>`） | 纯 SSR（零客户端 JS） |
| **Svelte 5 响应式岛屿** | 不可用 | 按需水合（`<Button>`、`<Switch>`） | `client:visible` 懒水合 |
| **反馈与加载原子** | 不可用 | 形变动画（`<LoadingIndicator>`） | `client:visible` 响应式 |
| **动态 JSX 表达式** | 不可用 | 原生求值（`{authorInfo.ui}`） | 编译期 / 客户端 |

## 2. 动态表达式与数据映射

MDX 允许你用文件顶部的 `export const` 声明作用域内的常量，这些常量既可以在行内求值，也可以映射到模板中进行渲染：

- **核心框架**：{authorInfo.framework}
- **UI 引擎**：{authorInfo.ui}
- **设计令牌**：{authorInfo.tokens}
- **架构模式**：{authorInfo.architecture}

数组与集合可以动态渲染成网格布局：

<div class="grid grid-cols-1 md:grid-cols-2 gap-4 my-6">
  {showcaseItems.map((item, idx) => (
    <div key={item.name} class="p-4 rounded-xl border border-[var(--outline-variant)] bg-[var(--surface-container-low)]">
